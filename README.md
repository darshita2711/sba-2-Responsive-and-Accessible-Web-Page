## Responsive and Accessible Web Page
## Description

This project is a responsive and accessible web page created using HTML and CSS. The website is designed to work on different screen sizes and includes accessibility features to improve the experience for all users.

## Features
Responsive design
Semantic HTML
Accessible form elements
ARIA attributes
Responsive images
Keyboard-friendly navigation

## Technologies Used
HTML
CSS

## How to View the Project
1. Download or clone this repository.
2. Open the project folder.
3. Open the index.html file in a web browser.
